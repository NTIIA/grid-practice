# 电网知练

无需后端的静态刷题工具。题目来自用户提供的159页《国家电网有限公司高校毕业生招聘考试公共与行业知识题库》，共832题。

## 使用

在静态服务器中打开 `index.html`。GitHub Pages部署使用本仓库的Pages工作流；仓库Settings → Pages中的构建来源需设为GitHub Actions。

- 顺序、随机、章节、题型、未做题练习，背题模式。
- 自选题量、时长的限时自测、交卷结果与历史记录。
- 错题本、收藏、搜索、浏览器本地进度及JSON备份。
- 解析只在已提交且答错时显示；自测交卷前不显示解析。
- 待核验和损坏题默认不进入自测，学习者可自行选择是否包含。

## 内容与证据

每题analysis保存独立的知识点说明、核验状态、来源和校核提示。verified表示所列资料能够支持当前解释；conflict表示题干、答案或标注与资料存在差异；unverified表示没有充分的直接依据或题目存在歧义，不把推断伪装成官方结论。

解析为学习辅助整理，不是国家电网或培训机构发布的官方逐题答案。所有判分答案从用户提供的原始PDF提取，832题逐题一致。外部资料差异仅作解析提示，不修改答案。原题答案保存在originalAnswer和answerText。公开站点不提供原始PDF下载，可根据题号与页码对照个人持有的原文件。数字及政策均按题干所指时点理解。

培训机构公开资源只作参考，没有批量复制机构付费题库。外部来源版权属于各原权利人。MIT许可仅适用于本项目自行编写的HTML、CSS、JavaScript代码，不覆盖原题库PDF、题目文本和引用材料。

每位访客的答题记录保存于自己的浏览器，不公开上传，不自动跨设备同步。
